# Which equipment got the balance buff?

Generated 2026-08-04 from the live monsterhunternow.com payload, which has **not** yet been updated for the patch.

The in-game notice says the adjusted gear is *boss material forged equipment, and some
early stage released monster material equipment*. So this list is ordered:

1. **Boss material** — the 8 series whose monster is an Elder Dragon.
2. **Early released monsters** — every other series, oldest monster first.

## The pattern so far

On the Kushala Set, the piece's **second listed skill** went from Lv1 to Lv2 on 4 of 5
pieces. The chest (Kushala Cista, Partbreaker) did **not** change. That is one data
point, not a rule — the tables below print what the source says so you can compare
against the game, whatever the real rule turns out to be.

Only pieces whose second skill is currently **Lv1 and has a cap above 1** can gain that
buff, so only those are listed — a skill like Lock On maxes at 1 and can never move.
`?` is for you to fill in.

Legend: **bold** = the second skill, the buff candidate.
